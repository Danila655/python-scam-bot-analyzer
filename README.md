# Игровой тренажёр «Кибердетектив: Распознай скам»

Консольная игра на Python, которая учит распознавать мошеннические сообщения.

Игрок читает сообщение, выбирает один из двух вариантов и получает объяснение:

- `1` — это скам
- `2` — безопасное сообщение

За правильный ответ начисляются очки. За ошибку уменьшается количество жизней. В конце игры показывается итог, звание и признаки скама.

## Запуск

```bash
python main.py
```

## Структура проекта

Проект состоит ровно из 5 файлов:

```text
analyzer_scam_bot/
├── data.py              — база сообщений и случайная выборка кейсов
├── config.py            — константы и настройки игры
├── rules_results.py     — правила игры и итоговый экран
├── question_answer.py   — показ вопроса, ввод ответа, проверка ответа и звание
└── main.py              — ядро: подключение всех файлов, игровой цикл и запуск
```

## Разделение работы на 2 команды

### Команда 1

Отвечает за файлы:

```text
data.py
config.py
rules_results.py
```

Задачи:

- подготовить базу сообщений
- настроить константы игры
- сделать экран правил
- сделать итоговый экран
- подготовить список признаков скама

### Команда 2

Отвечает за файлы:

```text
question_answer.py
main.py
```

Задачи:

- показать вопрос игроку
- получить ответ игрока
- проверить ответ
- начислить очки или уменьшить жизни
- определить итоговое звание
- собрать игру в `main.py`
- реализовать игровой цикл
